# 6102-construccion
Reimplementación TypeScript del módulo de decisión del proyecto MLOps.

## Requisitos
Node.js 20+ y TypeScript 5.8+.

## Ejecutar
```bash
npm install
npm test
```
`npm test` compila con `tsc` y ejecuta `node --test tests/*.test.mjs`.

## Estructura
- `dia01` a `dia11`: entregables y análisis por actividad.
- `src/`: implementación integrada.
- `tests/`: pruebas ejecutables.
- `python-original/`: copia íntegra del proyecto original usado en el contraste.
- `Informe_Contraste.pdf`: informe académico.

Nota de integridad: el repositorio se reconstruyó en una entrega integrada; no representa commits históricos diarios. Las notas identifican explícitamente mediciones que deben ejecutarse localmente en vez de inventar resultados.
